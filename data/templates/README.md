# Bộ template ký tự

Mỗi thư mục con là một nhãn (0-9, A-Z). Mỗi file PNG/JPG là một mẫu.

- Template được sinh tự động từ font bằng `tools/build_templates.py`.
- Có thể thêm ảnh ký tự thật đã cắt và đã xác minh vào đúng thư mục nhãn.
- Không đưa kết quả dự đoán chưa kiểm chứng vào bộ template.
- Kích thước template gốc không quan trọng; module nhận dạng sẽ chuẩn hóa về cùng kích thước với ảnh truy vấn.
